## Project Name: Video Game Inventory Application

## Project Description
This project is a Java-based Video Game Inventory Management System. It allows users to manage a collection of video games by adding, updating, viewing, and removing games from a SQLite database. The system supports both PC and Console games, storing details such as title, genre, developer, platform, average rating, and release date.

## Project Tasks
Object-Oriented Programming (Inheritance, Abstraction, Polymorphism)
JDBC for database connectivity and SQL operations
Exception handling and input validation in Java
Designing and implementing relational database schema

## Language Used
Java
SQLite
